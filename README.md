# High-Performance Async Proxy Validator

Профессиональный асинхронный валидатор прокси с поддержкой протоколов HTTP, HTTPS, SOCKS4 и SOCKS5. Инструмент разработан с упором на максимальную производительность, масштабируемость и чистоту кода, что делает его отличным решением для DevOps-пайплайнов, систем мониторинга и коммерческого использования.

## 🚀 Основные особенности

* Полная асинхронность (asyncio + aiohttp): Обработка сотен одновременных соединений без блокировки потоков.
* Мультипротокольность: Автоматическое распознавание и проверка HTTP, HTTPS, SOCKS4 и SOCKS5 прокси.
* Персистентность (SQLite): Автоматическое сохранение результатов аудита, статусов и истории латентности в реляционную базу данных.
* Красивый CLI интерфейс (rich): Наглядный прогресс-бар и статус выполнения в реальном времени.
* Гибкая настройка: Управление таймаутами, лимитами параллелизма и целевыми URL через аргументы командной строки.

---

## 🛠 Технологический стек

* Python 3.10+
* aiohttp / aiohttp-socks — асинхронный HTTP-клиент и поддержка прокси-соединений
* rich — консольный интерфейс нового поколения
* SQLite3 — встроенное хранилище данных для истории проверок

## 📦 Установка и запуск

1. Клонируй репозиторий:
   git clone [https://github.com/твой_логин/async-proxy-validator.git](https://github.com/твой_логин/async-proxy-validator.git)
   cd async-proxy-validator

2. Установи зависимости:
   pip install -r requirements.txt

3. Запусти валидатор:
   python main.py -i proxies.txt -o alive_result.json -c 50

---

## ⚙️ Параметры командной строки (CLI)

| Аргумент | Описание | По умолчанию |
| :--- | :--- | :--- |
| -i, --input | Путь к входному файлу со списком прокси | Обязательный |
| -o, --output | Путь для сохранения JSON-отчета | alive_proxies.json |
| -d, --database | Путь к файлу базы данных SQLite | proxy_audit.db |
| -t, --timeout | Таймаут сетевого запроса в секундах | 5.0 |
| -c, --concurrency | Максимальное число параллельных потоков | 100 |
| --url | URL-адрес для проверки соединения | [https://httpbin.org/ip](https://httpbin.org/ip) |

## 📄 Формат файла прокси (Input File Format)

Файл со списком прокси представляет собой текстовый документ, где каждый эндпоинт указан с новой строки:

# IP и порт (по умолчанию HTTP)
192.252.215.5:16137

# С явным указанием протокола
[http://103.124.139.170:8080](http://103.124.139.170:8080)
socks4://47.251.127.154:1080
socks5://182.16.171.65:51459
